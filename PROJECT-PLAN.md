# Project plan

## Minimum viable experience

- Clear home page with service value proposition and primary quote CTA.
- Service and area pages with consistent navigation.
- About, pricing and contact pages.
- Accessible quote form with validation and Netlify Forms integration.
- Responsive layout, FAQ accordion, gallery lightbox and mobile CTA.

## Distinction-focused enhancements

- Evidence-led UX decisions in `UX-DESIGN.md`.
- Repeatable testing and accessibility evidence in `TESTING.md`.
- Unique page titles, descriptions, canonical URLs, Open Graph data and JSON-LD.
- Meaningful commit history and a clear README explaining setup, deployment,
  credits and known limitations.
- Honest content: replace any draft claims, sample reviews or placeholder SEO
  tokens with verified business information before submission.

## Delivery sequence

1. Confirm the final business details, image licences and review permissions.
2. Run the testing checklist and fix defects.
3. Capture UX and accessibility evidence.
4. Review the README and remove any remaining placeholders.
5. Commit the finished work to the new repository.
6. Deploy to Vercel, configure the quote-form endpoint, and record the live URL.

## Assessment boundary

The student must make the final design/content decisions, provide authentic
research evidence, verify credits and submit the assessed project. This plan
is a working guide, not a substitute for the student's own assessed evidence.
